# DIGIVOTE - Digital Voting System

A secure Python-based digital voting application with MySQL database integration, featuring a graphical user interface built with Tkinter.

## Features

- ✅ Voter ID verification system
- ✅ Head Boy/Head Girl elections
- ✅ Admin panel for candidate management
- ✅ Secure vote counting with MySQL
- ✅ Image support for candidates
- ✅ Fade-in/fade-out transitions
- ✅ Hover effects and modern UI
- ✅ Prevention of duplicate voting

## Security Features

- Environment variables for secure credential management
- Parameterized SQL queries to prevent injection
- Voter authentication system
- Admin password protection
- Secure vote storage

## Technology Stack

- **Backend**: Python 3.x
- **Database**: MySQL
- **GUI**: Tkinter
- **Image Processing**: Pillow (PIL)
- **Database Connector**: mysql-connector-python

## Prerequisites

Before you begin, ensure you have the following installed:

- Python 3.7 or higher
- MySQL Server 5.7 or higher
- pip (Python package manager)
